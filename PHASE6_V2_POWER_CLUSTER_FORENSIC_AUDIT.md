# Phase 6 Final Forensic Audit of V2 Power Analysis and Event Independence

## 1. Power Methodology
The power analysis uses an analytical calculation for a one-sample z-test on the mean excess return.
- **Hypothesis**: 
  - $H_0$: mean excess return $= 0$
  - $H_1$: mean excess return $= \delta$ (where $\delta$ is the minimum detectable effect)
- **Methodology**: The test evaluates the standardized effect size using a normal approximation (Z-test), driven by the standard error ($SE$) of the baseline return distribution.
- **Standard Error**: $SE = \frac{\text{Baseline Std Dev}}{\sqrt{N_{\text{eff}}}}$
- **MDE Calculation**: $MDE = (Z_{1-\alpha/2} + Z_{\beta}) \times SE$. For $\alpha = 0.05$ (two-tailed) and Power = 80%, $Z_{1-\alpha/2} \approx 1.96$ and $Z_{\beta} \approx 0.84$.
