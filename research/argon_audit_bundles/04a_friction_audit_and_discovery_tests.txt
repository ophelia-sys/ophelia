## 2. Exact Mathematics of Friction in R

### Standard Institutional Position Sizing
Ophelia sizes positions to equalize risk across varying stop distances:
$$\text{Structural Risk} = R_{\text{usd}} = \$100.00$$
$$\text{Structural Stop Distance} = \Delta_{\text{SL}} = |P_{\text{entry}} - P_{\text{sl}}|$$
$$\text{Stop Distance Percentage} = s_{\%} = \frac{\Delta_{\text{SL}}}{P_{\text{entry}}}$$
$$\text{Executed Quantity} = Q = \frac{R_{\text{usd}}}{\Delta_{\text{SL}}}$$

### Executed Notional
$$\text{Entry Notional} = N_{\text{entry}} = Q \times P_{\text{entry}} = \frac{R_{\text{usd}}}{s_{\%}}$$
$$\text{Exit Notional} = N_{\text{exit}} = Q \times P_{\text{exit}}$$

### Trade Costs (USD)
$$\text{Exchange Fee} = N_{\text{entry}} \times f_{\text{entry}} + N_{\text{exit}} \times f_{\text{exit}}$$
$$\text{Slippage Cost} = N_{\text{entry}} \times \sigma_{\text{entry}} + N_{\text{exit}} \times \sigma_{\text{exit}}$$
$$\text{Funding Cost} = \frac{N_{\text{entry}} + N_{\text{exit}}}{2} \times r_{\text{fund}} \times t_{\text{duration}}$$
$$\text{Total Friction (\$)} = \text{Exchange Fee} + \text{Slippage Cost} + \text{Funding Cost}$$

### Conversion into R-Multiples
$$\text{Fee}_R = \frac{\text{Exchange Fee}}{R_{\text{usd}}} = \frac{N_{\text{entry}} \times f_{\text{entry}} + N_{\text{exit}} \times f_{\text{exit}}}{R_{\text{usd}}} \approx \frac{2 \times f_{\text{rate}}}{s_{\%}}$$
$$\text{Slippage}_R = \frac{\text{Slippage Cost}}{R_{\text{usd}}} \approx \frac{2 \times \sigma_{\text{rate}}}{s_{\%}}$$
$$\text{Funding}_R = \frac{\text{Funding Cost}}{R_{\text{usd}}}$$
$$\text{Net } R = \text{Gross } R - \text{Fee}_R - \text{Slippage}_R - \text{Funding}_R$$

## 4. The User's "8% of P&L" Observation Explained

The user noted: *"Fees appear to represent roughly 8% of total profit or loss, not 8% of invested amount or symbol movement."*

### Mathematical Derivation of the 8% Phenomenon
1. Suppose a trader opens a position with leverage $L$ or sizes a position to target a $1.25\%$ price move:
   $$\text{Price Gain} = \frac{\Delta P}{P} = 1.25\%$$
   $$\text{Gross P\&L} = \text{Notional} \times 1.25\%$$
2. The exchange charges 0.05% on entry notional and 0.05% on exit notional:
   $$\text{Round-trip Fees} \approx \text{Notional} \times (0.05\% + 0.05\%) = \text{Notional} \times 0.10\%$$
3. Taking the ratio:
   $$\frac{\text{Round-trip Fees}}{\text{Gross Realized P\&L}} = \frac{\text{Notional} \times 0.10\%}{\text{Notional} \times 1.25\%} = \frac{0.10}{1.25} = \mathbf{0.080} = \mathbf{8.0\%}$$
4. Alternatively, with a Maker entry (0.02%) and a Taker exit (0.05%):
   $$\text{Round-trip Fees} = 0.07\% \times \text{Notional}$$
   On a $+0.875\%$ target move:
   $$\frac{0.07\%}{0.875\%} = \mathbf{8.0\%}$$

### Conclusion on the 8% Observation
- **NOT an exchange fee mechanism:** BingX does not charge 8% of trade profits or losses.
- **Derived accounting ratio:** The 8% figure is the natural consequence of dividing standard 0.05%–0.10% notional fees by typical $+0.9\%$ to $+1.3\%$ crypto day-trade targets.
- **Asymmetric on losses:** On a stopped trade losing $-0.40\%$, the same 0.10% round-trip fee equals $\frac{0.10\%}{0.40\%} = \mathbf{25.0\%}$ of the loss added as an extra penalty.

# Standard institutional risk allocation per trade for USD calculations
R_USD_UNIT = 100.00  # $100 risk per trade

# Verified BingX Fee Rates from actual exchange fills:
BINGX_MAKER_FEE_RATE = 0.00020  # 2.0 bps (VIP0)
BINGX_TAKER_FEE_RATE = 0.00050  # 5.0 bps (VIP0)

# Typical 8-hour perpetual funding rate (0.01% = 0.0001 per 8h, or 0.0001 / 480 per minute)
FUNDING_RATE_PER_MINUTE = 0.0001 / 480.0


def calculate_trade_friction_record(
    cand: Phase12Candidate,
    entry_fee_rate: float,
    exit_fee_rate: float,
    entry_slip_rate: float,
    exit_slip_rate: float,
    apply_funding: bool = True,
    use_reforecast_exit: bool = False
) -> Dict[str, Any]:
    """Calculates all 16 required friction fields for a single trade."""
    entry_px = cand.entry_price
    sl_px = cand.sl_price
    direction = cand.direction.upper()

    # Determine exit price and duration
    if use_reforecast_exit and cand.reforecast_policy == "EARLY_EXIT_AT_15M":
        # Early exit at T+15m
        exit_px = cand.entry_price * (1.0 + cand.gross_realized_r * (cand.risk_amount / cand.entry_price)) # placeholder or actual
        # From candidate reforecast
        exit_reason = "REFORECAST_EARLY_EXIT"
        exit_time_min = 15
        gross_r = cand.reforecast_net_r_base # will adjust below
    else:
        exit_px = cand.exit_price
        exit_reason = cand.exit_reason
        exit_time_min = cand.time_to_exit_min
        gross_r = cand.gross_realized_r

    # Structural SL distance
    sl_distance = abs(entry_px - sl_px)
    stop_distance_pct = sl_distance / max(1e-6, entry_px)

    # Actual quantity sized for $100 risk
    qty = R_USD_UNIT / max(1e-6, sl_distance)

    # 1. Entry notional
    entry_notional = qty * entry_px

    # 2. Exit notional
    exit_notional = qty * exit_px

    # 6. Gross price PnL
    if direction == "LONG":
        gross_price_pnl = qty * (exit_px - entry_px)
    else:
        gross_price_pnl = qty * (entry_px - exit_px)

    # 7, 8, 9. Exchange fees
    entry_fee = entry_notional * entry_fee_rate
    exit_fee = exit_notional * exit_fee_rate
    exchange_fee = entry_fee + exit_fee

    # 10. Funding
    if apply_funding:
        avg_notional = (entry_notional + exit_notional) / 2.0
        funding_cost = avg_notional * FUNDING_RATE_PER_MINUTE * exit_time_min
    else:
        funding_cost = 0.0

    # 11. Slippage cost
    entry_slippage_cost = entry_notional * entry_slip_rate
    exit_slippage_cost = exit_notional * exit_slip_rate
    slippage_cost = entry_slippage_cost + exit_slippage_cost

    # 12. Gross PnL
    gross_pnl = gross_price_pnl

    # 13. Net PnL
    net_pnl = gross_pnl - exchange_fee - slippage_cost - funding_cost

    # 15. R denominator
    r_denominator = R_USD_UNIT

    # 16. Net PnL expressed in R
    gross_r_calc = gross_pnl / r_denominator
    fee_r = exchange_fee / r_denominator
    slippage_r = slippage_cost / r_denominator
    funding_r = funding_cost / r_denominator
    net_r_calc = net_pnl / r_denominator

    # Friction percentages of executed notional
    total_friction_cost = exchange_fee + slippage_cost + funding_cost
    total_executed_notional = entry_notional + exit_notional
    friction_pct_of_notional = (total_friction_cost / max(1e-6, total_executed_notional)) * 100.0

    # Friction as R per trade
    friction_r_per_trade = fee_r + slippage_r + funding_r

    # Derived Fee / Gross PnL ratio (when gross_pnl != 0)
    fee_to_gross_pnl_pct = (exchange_fee / abs(gross_pnl) * 100.0) if abs(gross_pnl) > 1e-4 else 0.0

    return {
        "candidate_id": cand.candidate_id,
        "symbol": cand.symbol,
        "direction": cand.direction,
        "split": cand.split,
        "entry_notional": round(entry_notional, 2),
        "exit_notional": round(exit_notional, 2),
        "actual_quantity": round(qty, 6),
        "entry_price": round(entry_px, 4),
        "exit_price": round(exit_px, 4),
        "gross_price_pnl": round(gross_price_pnl, 2),
        "exchange_fee": round(exchange_fee, 4),
        "entry_fee": round(entry_fee, 4),
        "exit_fee": round(exit_fee, 4),
        "funding": round(funding_cost, 4),
        "slippage_cost": round(slippage_cost, 4),
        "gross_pnl": round(gross_pnl, 2),
        "net_pnl": round(net_pnl, 2),
        "structural_sl_distance": round(sl_distance, 4),
        "stop_distance_pct": round(stop_distance_pct * 100.0, 4),
        "r_denominator": round(r_denominator, 2),
        "gross_r": round(gross_r_calc, 4),
        "fee_r": round(fee_r, 4),
        "slippage_r": round(slippage_r, 4),
        "funding_r": round(funding_r, 4),
        "net_r": round(net_r_calc, 4),
        "friction_pct_of_notional": round(friction_pct_of_notional, 4),
        "friction_r_per_trade": round(friction_r_per_trade, 4),
        "fee_to_gross_pnl_pct": round(fee_to_gross_pnl_pct, 2),
        "exit_reason": exit_reason,
        "time_to_exit_min": exit_time_min,
        # Membership flags
        "pass_variant_d": cand.pass_variant_d,
        "pass_d4h": cand.pass_d4h,
        "tfm_reachable": cand.tfm_reachable_binary_60m,
        "pass_downside_gate": cand.pass_downside_gate,
        "reforecast_policy": cand.reforecast_policy
    }


def compute_cohort_friction_metrics(trades: List[Dict[str, Any]]) -> Dict[str, Any]:
    """Aggregates trade-level friction metrics for a cohort."""
    if not trades:
        return {
            "count": 0, "win_rate": 0.0,
            "total_gross_pnl": 0.0, "total_fee": 0.0, "total_slippage": 0.0,
            "total_funding": 0.0, "total_net_pnl": 0.0,
            "gross_r": 0.0, "fee_r": 0.0, "slippage_r": 0.0, "funding_r": 0.0, "net_r": 0.0,
            "mean_gross_r": 0.0, "mean_fee_r": 0.0, "mean_slippage_r": 0.0, "mean_funding_r": 0.0, "mean_net_r": 0.0,
            "profit_factor": 0.0,
            "mean_friction_pct_notional": 0.0, "mean_friction_r_per_trade": 0.0,
            "median_fee_to_gross_pnl_pct": 0.0
        }

    n = len(trades)
    wins = [t for t in trades if t["gross_r"] > 0]
    win_rate = (len(wins) / n) * 100.0

    total_gross_pnl = sum(t["gross_pnl"] for t in trades)
    total_fee = sum(t["exchange_fee"] for t in trades)
    total_slippage = sum(t["slippage_cost"] for t in trades)
    total_funding = sum(t["funding"] for t in trades)
    total_net_pnl = sum(t["net_pnl"] for t in trades)

    gross_r = sum(t["gross_r"] for t in trades)
    fee_r = sum(t["fee_r"] for t in trades)
    slippage_r = sum(t["slippage_r"] for t in trades)
    funding_r = sum(t["funding_r"] for t in trades)
    net_r = sum(t["net_r"] for t in trades)

    pos_r = sum(t["net_r"] for t in trades if t["net_r"] > 0)
    neg_r = abs(sum(t["net_r"] for t in trades if t["net_r"] < 0))
    pf = (pos_r / max(1e-6, neg_r)) if neg_r > 0 else (999.0 if pos_r > 0 else 0.0)

    mean_f_notional = np.mean([t["friction_pct_of_notional"] for t in trades])
    mean_f_r = np.mean([t["friction_r_per_trade"] for t in trades])

    # Fee to gross PnL percentage on winning trades
    win_fee_ratios = [t["fee_to_gross_pnl_pct"] for t in wins if t["fee_to_gross_pnl_pct"] > 0]
    median_fee_pnl = float(np.median(win_fee_ratios)) if win_fee_ratios else 0.0

    return {
        "count": n,
        "win_rate": round(win_rate, 2),
        "total_gross_pnl": round(total_gross_pnl, 2),
        "total_fee": round(total_fee, 2),
        "total_slippage": round(total_slippage, 2),
        "total_funding": round(total_funding, 2),
        "total_net_pnl": round(total_net_pnl, 2),
        "gross_r": round(gross_r, 2),
        "fee_r": round(fee_r, 2),
        "slippage_r": round(slippage_r, 2),
        "funding_r": round(funding_r, 2),
        "net_r": round(net_r, 2),
        "mean_gross_r": round(gross_r / n, 4),
        "mean_fee_r": round(fee_r / n, 4),
        "mean_slippage_r": round(slippage_r / n, 4),
        "mean_funding_r": round(funding_r / n, 4),
        "mean_net_r": round(net_r / n, 4),
        "profit_factor": round(pf, 2),
        "mean_friction_pct_notional": round(float(mean_f_notional), 4),
        "mean_friction_r_per_trade": round(float(mean_f_r), 4),
        "median_fee_to_gross_pnl_pct": round(median_fee_pnl, 2)
    }

    def test_notional_vs_pnl_fee_calculation(self):
        """Proves fee is charged on notional (entry*qty + exit*qty), never on PnL."""
        trade = calculate_trade_friction_record(
            cand=self.mock_cand,
            entry_fee_rate=0.0005,  # 5 bps
            exit_fee_rate=0.0005,   # 5 bps
            entry_slip_rate=0.0,
            exit_slip_rate=0.0,
            apply_funding=False
        )

        # Expected:
        # Stop distance = 20 / 2000 = 1.0% = 0.01
        # Qty = $100 / $20 = 5.0 units
        # Entry notional = 5.0 * $2000 = $10,000
        # Exit notional = 5.0 * $2030 = $10,150
        # Entry fee = $10,000 * 0.0005 = $5.00
        # Exit fee = $10,150 * 0.0005 = $5.075
        # Total fee = $10.075
        # Gross PnL = 5.0 * $30 = $150.00

        self.assertAlmostEqual(trade["entry_notional"], 10000.0, places=2)
        self.assertAlmostEqual(trade["exit_notional"], 10150.0, places=2)
        self.assertAlmostEqual(trade["exchange_fee"], 10.075, places=3)
        self.assertAlmostEqual(trade["gross_pnl"], 150.0, places=2)
        self.assertAlmostEqual(trade["net_pnl"], 139.925, places=2)

        # Fee in R = $10.075 / $100 = 0.10075R
        self.assertAlmostEqual(trade["fee_r"], 0.1008, places=3)
        self.assertAlmostEqual(trade["gross_r"], 1.5, places=2)
        self.assertAlmostEqual(trade["net_r"], 1.5 - 0.1008, places=3)

    def test_mathematical_derivation_of_user_8pct_claim(self):
        """Validates that a 0.10% notional fee equals ~8.0% of PnL on a 1.25% price gain."""
        entry_price = 1000.0
        # Price gain = +1.25%
        exit_price = entry_price * 1.0125
        qty = 10.0
        entry_notional = qty * entry_price    # $10,000
        exit_notional = qty * exit_price      # $10,125
        gross_pnl = qty * (exit_price - entry_price) # $125.00

        entry_fee = entry_notional * 0.0005   # $5.00
        exit_fee = exit_notional * 0.0005     # $5.0625
        total_fees = entry_fee + exit_fee     # $10.0625

        fee_to_pnl_ratio = total_fees / gross_pnl # 10.0625 / 125.0 = 0.0805 = 8.05%
        self.assertAlmostEqual(fee_to_pnl_ratio, 0.0805, places=3)

    def test_stop_distance_r_scaling_law(self):
        """Validates formula: friction_R = friction_notional / stop_distance_pct."""
        # 1. 0.50% stop distance -> 9 bps should equal 0.18R
        stop_pct_1 = 0.0050
        r_cost_1 = 0.0009 / stop_pct_1
        self.assertAlmostEqual(r_cost_1, 0.18, places=4)

        # 2. 0.25% stop distance -> 9 bps should equal 0.36R
        stop_pct_2 = 0.0025
        r_cost_2 = 0.0009 / stop_pct_2
        self.assertAlmostEqual(r_cost_2, 0.36, places=4)

        # 3. 2.00% stop distance -> 9 bps should equal 0.045R
        stop_pct_3 = 0.0200
        r_cost_3 = 0.0009 / stop_pct_3
        self.assertAlmostEqual(r_cost_3, 0.045, places=4)
